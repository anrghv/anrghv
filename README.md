# Anuj Raghav

I’m a PhD researcher in **Experimental High Energy Physics** at the **University of Delhi**, working with the **CMS Experiment at CERN**.

Currently, I’m working on **Higgs → gg analysis using Boosted Decision Trees (BDTs)**. You can find the project [here](https://github.com/anrghv/ml-hep).

Previously, I worked as an **HSF-India Fellow**, where I worked on the **H → WW analysis using CMS Open Data**, with a focus on making CERN Open Data more accessible and useful for researchers getting started in HEP. The project is available [here](https://github.com/anrghv/H-to-WW-NanoAOD-analysis).

You can read more about my work on my [personal website](https://anrghv.github.io/). It should be up to date—but if it isn’t, feel free to remind me :-)

### Research Interests
