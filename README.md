# Anuj Raghav 

I’m a PhD researcher in Experimental High Energy Physics at the University of Delhi, working with the CMS Experiment at CERN.
Currently, I’m working on the Higgs to gluon-gluon analysis using BDTs. You can find this [here](https://github.com/anrghv/ml-hep).
Before this, I worked as an HSF-India Fellow, where I worked on the H to WW analysis using CMS Open Data, with a focus on making CERN Open Data more accessible and useful for researchers getting started in HEP. Find it [here](https://github.com/anrghv/H-to-WW-NanoAOD-analysis)
You can read more about my work at [https://anrghv.github.io/](https://anrghv.github.io/). It should be updated. If it isn’t, feel free to remind me :-)

My research interests include open science, machine learning applications in High Energy Physics, and AI-driven analysis workflows.
